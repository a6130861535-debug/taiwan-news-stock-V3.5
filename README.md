# 台股重大公開資訊新聞分析 V3.5

這是一個使用 Streamlit 建立的台股新聞分析工具。

## 支援市場

- 上市（TWSE）
- 上櫃（TPEx）
- 興櫃（ESB）

## 主要功能

- 公司名稱 / 股票代號搜尋
- Google News RSS
- 重大新聞分類
- 正負面關鍵字分析
- 歷史事件研究
- +1 / +3 / +5 / +10 / +20 交易日報酬
- 平均值
- 中位數
- 上漲比例
- 最大漲幅
- 最大跌幅
- Q25 / Q75
- CSV 匯出
- Excel 匯出
- 圖表分析

## 啟動

streamlit run app.py

## Streamlit Community Cloud

Main file：

app.py

Dependencies：

requirements.txt

## 注意

本工具的歷史事件報酬統計屬於歷史資料分析，
不代表未來股價一定會按照相同方向變動。
